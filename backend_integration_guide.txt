PAGE: Login
FILE: src/pages/auth/Login.jsx
ROUTE: /auth/login
--------------------------------------------------
DATABASE TABLE: `users`, `session_logs`

FORM INPUTS:
- Email Address -> `users.email`
- Password -> `users.password` (Compare with hashed value)

LOGIC:
- On success, create record in `session_logs`:
  - `user_id`: users.id
  - `login_at`: NOW()

PAGE: Register
FILE: src/pages/auth/Register.jsx
ROUTE: /auth/register
--------------------------------------------------
DATABASE TABLE: `users`, `roles`

FORM INPUTS:
- First Name + Last Name -> `users.name` (Concatenate strings before insert)
- Email Address -> `users.email`
- Password -> `users.password` (Must hold hashed value)
- Role Selection -> `users.role_id` 
  - IF 'intern' -> SELECT id FROM roles WHERE name='intern'
  - IF 'lead' -> SELECT id FROM roles WHERE name='teamlead'
- Tech Stack -> `users.technology_id` (Link to `technologies` table)

--------------------------------------------------
DATABASE TABLES: `topics`, `questions`, `topic_assignments`, `submissions`

- Task List -> SELECT * FROM `questions` WHERE topic_id = (Current Topic ID)
- Difficulty -> `questions.difficulty` (ENUM: 'basic','medium','hard')
- BADGES:
  - Points -> `questions.marks`
  - Difficulty -> `questions.difficulty`

FORM/ACTION:
- Submit Solution -> INSERT/UPDATE `submissions`
  - `topic_assignment_id`: Link to current assignment
  - `question_id`: Current question
  - `code_answer`: Content from Code Editor
  - `status`: 'submitted'

--------------------------------------------------
